# WBSA Community Edition

## General introduction

- **What we built:** A browser-based tool for studying peptides—short chains of amino acids—and the chemical changes they carry.
- **Why it helps:** Researchers can turn experimental measurements into clear charts, compare possible explanations, and inspect the evidence behind each result.
- **How it works:** Enter a peptide sequence and measurement data, run an analysis, then review, save, or share the results.

## Specific software improvements

- **Manual and automatic analysis:** Added tools to check known modification positions and compare possible locations of unknown changes.
- **Specialized chemistry tools:** Added Lanthiopeptide Chemistry with ready-made presets and editable custom rules.
- **More ways to compare results:** Added a second ranking method based on peptide fragment evidence, alongside the original scoring method.
- **Clearer charts:** Improved peptide fragment labels, added show/hide details, and provided downloads of the supporting measurements.
- **Reusable work:** Added saved analysis plans, spectrum views, and custom configurations.
- **Flexible exports:** Added figure editing and exports including CSV, PDF, Word, and Excel.
- **Getting-started support:** Added example datasets, English and Chinese guides, and Docker setup instructions for Windows, macOS, and Linux.
